# Qt Text Editor

A desktop text editor developed in C++ using the Qt Widgets framework.

This project was originally developed as part of my university coursework and is currently being improved with additional text editing and file management functionality.

## Features

- Graphical user interface built programmatically with Qt Widgets
- Menu bar and toolbar
- New document action
- Open and save actions
- Cut, copy and paste actions
- Font customization
- Text color customization
- Print action
- Keyboard shortcuts

## Technologies

- C++
- Qt
- Qt Widgets
- Qt Creator

## Project Structure

- `main.cpp` – application entry point
- `mainwindow.cpp` – main window implementation
- `mainwindow.h` – main window declaration
- `Resources.qrc` – application resources and icons

## Current Status

The user interface is implemented and the project is currently being expanded to make all editor actions fully functional.

## Planned Improvements

- File opening and saving
- Save As functionality
- Unsaved changes warning
- Font and text color selection
- Improved keyboard shortcuts
- Interface improvements
